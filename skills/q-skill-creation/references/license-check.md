# License Check

Use before borrowing from another skill, repository, tutorial, or article.

## Rules

- Ideas, patterns, and product structure can be reimplemented independently.
- Copying code, scripts, prompts, schemas, text, images, or assets requires
  license compatibility and attribution.
- If a source has no clear license, do not copy material into q-workflow-hub.
- MIT material is generally compatible with Apache-2.0 when the MIT notice is
  preserved for copied substantial portions.
- Record materially used references in `THIRD_PARTY_NOTICES.md`.

## Minimum Record

- Source repository or URL.
- License found.
- What was used: idea/pattern only, adapted code, copied text, or asset.
- Whether attribution or vendored license text is required.
- Validation that no private data or credentials were copied.
