# Dispatch Agent

This is sufficient for ordinary delegation after the entry skill. Load a
specialist contract only for an unresolved domain decision.

1. Select a stable role and a useful bounded scope. Reuse the current model and
   effort. Keep independent review separate from creation; use disjoint files
   for parallel writers. The main agent remains the integration owner.
2. Brief the agent once: goal, relevant paths/current state, allowed actions,
   protected scope, acceptance/stop condition, and desired result/evidence.
   A concise paragraph or bullets are sufficient. Supply only context needed
   for that task. Use a file report only for bulky evidence or a release contract.
3. Before spawning, tell the user the role and mission in ordinary concise prose.
   Multiple roles may share an update if each scope and permission is clear.
   Record the returned real run handle in the task/review evidence; use the
   stable English alias with Chinese codename on first mention.
4. Continue independent work. Read the result before dependent edits; reconcile
   pending actions after interruption. Send a follow-up only for missing facts,
   authority, evidence or a required repair, not to restyle a useful answer.
5. Integrate findings with dispositions and test affected changes. Keep role/run,
   evidence paths and unresolved gaps once in the existing work item. Reuse the
   same reviewer for a fix; no automatic scoring or extra learning round.

Required result semantics: what was checked/changed, findings, evidence and
remaining gaps. The run handle returned by the host is valid identity evidence;
the parent may attach it without another identity-only model turn.

For a machine-consumed packet or durable multi-stage/release handoff, read
`../references/handoff-protocol.md` and satisfy the actual consumer schema.
That is an additional contract, not the default for every real subagent.

Explicit independent domain/release reviews remain required. If unavailable,
report that gap; do not relabel a local pass as independent or imply publication.
An already authorized external action needs no second approval after review.
