# Stuck Lateral

Use when direct domain search has stalled or the current approach keeps
returning the same weak options.

## Steps

1. State the blockage concretely.
2. Identify what kind of problem it is:
   - discovery;
   - reliability;
   - onboarding;
   - evaluation;
   - automation;
   - interaction design;
   - operational process.
3. Pick 2-4 adjacent domains that solve a similar shape of problem.
4. Search for mechanisms, not slogans. Look for checklists, workflows, failure
   modes, scoring rubrics, or handoff patterns.
5. Convert each useful analogy into a testable project idea.
6. Keep only ideas that can be validated with a small local experiment or a
   concrete document change.

## Output

- Blockage.
- Adjacent domains searched.
- Mechanisms found.
- Candidate experiments.
- Recommended experiment.
