# Search Log Template

Use this format in a project handoff file, personal source registry, or work
item when a search lesson should survive the current chat.

```markdown
## <Topic Or Source Lesson>

- Date: <YYYY-MM-DD>
- Objective: <what the research needed to answer or validate>
- Project/task: <where this applies>
- Source roles:
  - <stable source / boundary source / primary docs / example / counterexample>
- Queries or discovery path:
  - `<query or path>`
- Useful sources:
  - <source name or path> - <why it was useful>
- Findings:
  - <short finding>
- Warnings:
  - <warning> - Severity: <blocking/degraded/informational/future risk>
- Validation score:
  - <0-10 or not applicable> - <short reason>
- Validation:
  - <what was tested or verified>
- Next action:
  - <what to do with the result>
```

Keep entries short. Store large transcripts, downloaded pages, and generated
artifacts outside public repositories unless they are explicitly public-safe.
