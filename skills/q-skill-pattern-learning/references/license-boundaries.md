# License Boundaries

Use before borrowing from another skill, repository, tutorial, article, or
prompt pack.

## Default Boundary

- Ideas, patterns, workflow phases, and validation concepts can be reimplemented
  independently.
- Copying code, prompts, schemas, text, images, or assets requires a compatible
  license and attribution.
- If a source has no clear license, do not copy material into q-workflow.
- If a source is private, company-internal, or customer-related, do not publish
  derived material without explicit approval and a data-exposure scan.

## Minimum Record

- Source path or URL.
- License found or `unknown`.
- Material used: idea/pattern only, adapted code, copied text, schema, or asset.
- Attribution requirement.
- Validation that credentials, private data, and customer material were not
  copied.

When the learning output belongs in `q-workflow-hub-public`, update
`THIRD_PARTY_NOTICES.md` for material references that shaped the change.
