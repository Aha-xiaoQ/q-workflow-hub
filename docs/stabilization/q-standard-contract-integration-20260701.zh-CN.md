# 标准检查：集成说明

[English](q-standard-contract-integration-20260701.md) · **简体中文**

历史候选方案参考，日期为 2026-07-01。本文不代表稳定版发布声明；选择包版本请参阅[版本指南](../releases/q-workflow-v1.2.zh-CN.md)。

## 目的

文字标准需要可检查的关卡、明确的警告与阻塞级别，以及回归测试覆盖，才能可靠指导项目工作。

## 检查覆盖

标准检查器覆盖严格的专家分派卡、依赖阻塞项、状态行示例、UTF-8 与乱码、规则块解析，以及必需的规则标识。角色、路由与任务状态必须分开表达。

## 采用前验证

对受影响的 q-workflow 技能和内置样本运行检查器：

```text
q_standard_check.py --root <q-workflow> --self-test
```

同时对修改的约定、检查器和输出文件运行 `encoding_guard.py`，并执行 `git diff --check`。检查失败原因，修复后重新验证。

## 同步与发布

有针对性地同步源文件、运行副本、引导副本和维护中的变体，再重复相同检查。本地检查通过不代表获得发布或迁移无关项目的授权。候选状态与稳定发布状态必须分开。
