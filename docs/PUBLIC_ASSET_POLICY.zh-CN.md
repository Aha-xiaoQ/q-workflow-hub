# 公开素材准入

[English](PUBLIC_ASSET_POLICY.md) · **简体中文**

创建新素材时就应分类，而不是等到推送前才分类。

| 分类 | 含义 | 是否可发布 |
| --- | --- | --- |
| private | 个人状态、账号自动化、凭据、操作证据或受限资料 | 不可发布 |
| review-required | 新增或修改的技能、脚本、参考资料、测试样本或第三方组件 | 审核前不可发布 |
| public-snapshot | 已获准进入本仓库的准确审核内容 | 仅可发布已审核版本 |

技能 ID 不代表永久发布许可。内容一旦修改，就重新归入待审核。公开发布包应是经过挑选的快照，而不是已安装技能目录的副本。未经批准的技能应排除，不能仅为满足新依赖就一并发布。

## 准入检查清单

1. 从公开仓库开始，保留其发布专属修复。
2. 对规范化文本做比较，忽略换行符和解释器缓存差异。
3. 选定准确源文件，不复制凭据、私人历史、生成的转录文本、本机注册表、个人路径或样例输出。
4. 检查依赖、相对链接、许可证与来源。将经验改写为通用指导，不引入个人证据。
5. 运行公开内容扫描、针对性测试、安装检查和独立审核。
6. 记录纳入和延后范围，将已审核修改整理为一个提交。除非另获批准发布新版本，否则保留现有版本标签。

## 默认保持私有

账号专属上传或发布技能不属于此包。本机授权路径注册表和视频资料提取产物也应保持私有，即使通用提取工具可以公开。Cookie 文件路径和来源网址本身也可能敏感。

忽略规则只是便利工具，不是安全边界：已跟踪文件和任意命名的文件仍需检查。不要在未经审核的维护者安装目录中使用 `git add .`。

## 确认安装范围

安装前请查看[当前 README](../README.zh-CN.md#包含哪些内容)中的技能清单，以及[版本说明](releases/q-workflow-v1.2.zh-CN.md)。历史维护记录只描述对应版本，不代表当前可用范围。
