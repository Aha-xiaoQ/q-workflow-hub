# Docs

This directory keeps supporting documentation out of the first-screen promotion
entry while preserving a stable structure shared with company variants.

- `onboarding/`: after-setup guidance and machine/bootstrap instructions.
- `product/`: product principles, collaboration mechanisms, and design intent.
- `governance/`: public sync policy and variant-delta records.

The root README, quickstarts, and root onboarding files remain the public-facing
entry points for compatibility.
