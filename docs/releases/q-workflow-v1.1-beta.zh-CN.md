# q-workflow v1.1-beta

[English](q-workflow-v1.1-beta.md) | **简体中文**

这是优先面向 Windows 的公开起步包，提供基于文件的项目恢复、显式任务状态、可复用技能与审查检查。
本版本仍为 beta 软件。

## 变化

- 加强任务指针验证与试点状态转换。
- 根据注册表安装全部 17 个随包源码技能，以及生成的助手配置档案。
- 支持空工作流中心的初始化、首个任务注册和 TODO 显示元数据。
- TODO 名称保留用户原始文字；说明字段目前使用中文框架。这不是自动翻译。
- 公开安装测试覆盖真实已安装命令、镜像重建、软件包一致性、更新时保留现有内容及故障注入回滚。

## 安装与迁移

请使用[中文](../../QUICKSTART.zh-CN.md)或[英文](../../QUICKSTART.md)快速开始。
需要 Git、Python 3.10+ 和 Windows PowerShell。

本次分发启用新的公开 Git 历史。已有起步包副本不得将旧历史合并到本次发布中。
请私下保留本地修改，将 `v1.1-beta` 克隆到单独目录，再按照文档使用更新工具，
更新现有的私人工作流中心和运行时。不要把重新运行初始化程序当作升级方式：它会写入安装配置。

初始化程序只会在运行时状态镜像目录不存在时创建它。已有或部分初始化的镜像需要显式验证和修复，
不会被静默覆盖。TODO 提交会更新权威文件；若要重建只读镜像，先使用
`q_base_command.py --preflight-sync`，再使用 `--sync-runtime --audit`。
请从已安装的技能目录运行这些命令，并使用你自己的配置档案。

## 验证与限制

安装检查覆盖 Windows 上的全新安装、状态恢复、更新时保留现有内容以及回滚。

已有用户应在更新前检查已配置的路径、权限和集成，随后通过编程智能体验证正常接续流程。

## 恢复

更新前备份私人工作流中心与运行时。软件包切换失败时，更新工具会回滚；即使安装成功，
也应在验证正常接续流程后再决定是否丢弃私人备份。本版本支持快速开始文档中记录的迁移更新路径。
